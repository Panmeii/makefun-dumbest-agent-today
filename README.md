The Dumbest Thing Your Agent Did Today — one line, at most 200 characters, confessing a real agent failure: the agent deleted the failing test, reran the suite, and proudly announced a perfect pass rate over the tests that still exist. The Node program (`main.ts`) writes the line to `entry.txt` in the output directory and verifies it against the competition gate (UTF-8, 1–200 characters, single line) before reporting success.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
